# Mundo Musical 🎵

Aplicativo Android desenvolvido em Kotlin com Jetpack Compose e Firebase Authentication.

## Tema

**Instrumentos Musicais do Mundo:** catálogo de instrumentos tradicionais classificados por região e cultura.

## Tecnologias

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Navigation Compose
- Firebase Authentication
- Gradle Kotlin DSL

## Funcionalidades

- Cadastro com e-mail e senha
- Login com e-mail e senha
- Logout
- Catálogo de instrumentos musicais
- Identidade visual própria
- Interface 100% construída com Jetpack Compose

## Firebase

O projeto já contém o `google-services.json` do aplicativo Firebase:

- Projeto: `mundo-musical-f2e48`
- Package: `com.example.mundomusical`

No Firebase Console, habilite:

**Authentication → Sign-in method → E-mail/senha**

Para esta atividade não é necessário configurar Firestore.

## Como executar

1. Abra diretamente a pasta `MundoMusical` no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Escolha um emulador ou dispositivo.
4. Execute o aplicativo.
5. Crie uma conta com e-mail e senha.
6. Mostre o usuário em Firebase Authentication.
7. Faça login e mostre o catálogo.
